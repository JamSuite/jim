# blueprint — blueprint

*The current, present-tense specification of the `blueprint` group: its
responsibilities, exposed and required surface, structure, and load-bearing
invariants. Generated by `/jim:blueprint blueprint`; every claim traces to the
group's specs, ARCHITECTURE.md, and code.*

## Responsibility

The `blueprint` group is jim's living-intent machinery: group `000-blueprint`s
and the project context map (`/jim:blueprint`), the derived cross-group
contract graph and its reconcile pass, the verification engine
(`/jim:verify` — invariants, contract edges, retirement), and the partition's
own lifecycle (`/jim:partition` — adoption, territory readiness, rename,
split, merge, health). It holds the doctrine's write surface (single-writer,
human-gated, criticality-graded), its read-only judge and gatherer subagents,
and the canonical gate-presentation, present-tense, and provenance rules the
rest of the plugin cites.

## Provides

- `/jim:blueprint` **write surface** — group blueprints (generate and
  targeted update), the project map, reconcile, retire, and the caller-driven
  migrate arms (rename/split/merge). Guarantee: the sole map/blueprint write
  authority; every edit grades by the shared downgrade rule; a violated
  invariant is never silently rewritten; migrate arms defer commits to the
  calling orchestrator with no re-gate.
- `/jim:verify` **engine + VERIFY-OUTCOME contract** — whole-group, contract
  (`--contracts`), retirement (`--retirement`), and change-scoped
  (`--from-review`/`--since`) verification. Guarantee: facts-not-verdicts; the
  mechanical floor always runs and is never appetite-gated; outcomes are
  handed to callers as structured records; no verdict artifact persists.
- `jimverify.sh` **verification-floor CLI** — `parse`/`territory`/`check`/
  `scope-census`/`faces`/`edges`/`contracts-check`/`health`/`faces-aggregate`.
  Guarantee: deterministic sanitized TSV, location-only evidence; never
  executes a config- or blueprint-derived command string; the `edges` verb is
  the plan-time blast-radius fact source.
- `jimpartition.sh` **partition CLI** — the scan/ingest/aggregate/coverage
  substrate, rename/split/merge preflights and rewrites, and the health facts.
  Guarantee: `ingest` is the valid-relpath + tracked-endpoint trust boundary
  over untrusted extractor output; the script never resolves or executes a
  config-derived command.
- `@jim:judge` **single-claim judge** — read-only verdicts on one invariant,
  one contract-edge side, or one retirement claim; dispatched by the verify
  orchestrator (and by the review skill under its own grant when the engine
  runs inline). Guarantee: Read/Glob/Grep only; structured verdict contract;
  retirement burden inverts fail-toward-keeping.
- `@jim:gatherer` **per-group evidence gatherer** — read-only, one group per
  dispatch, fail-closed invariant marking.
- **Canonical rule docs** — `gate-presentation.md`, `present-tense.md`,
  `provenance.md` under `skills/blueprint/references/`. Guarantee: defined
  once, cited by path from every gate-presenting or composing skill, enforced
  by dedicated test files.
- `/jim:partition health` **partition-health sensor** — read-only trend
  interpretation with an advisory split/merge remedy; persists no verdict.
- `scripts/jim-deps-refs.sh` **dependency-edge extractor** — jim's own
  markdown/bash reference channels on the ingest line contract; activated only
  by an operator-pasted `deps_command_<name>` config value.

## Requires

- `platform.jimledger-cli` — the ledger channel for every run: stage events,
  `metrics`/`diff`/`diff-range`/`files`/`files-range`, `updates-since`,
  `last-reconcile`/`reconcile-series`, and the path-scoped commit verbs
  (`commit-blueprint`/`commit-map`/`commit-verify`/`commit-rename`/
  `commit-split`/`commit-merge`) plus `move-spec-dir`/`rename-tracked`.
- `platform.jimconf-cli` — knob resolution (`auto_blueprint`,
  `blueprint_regen_threshold`, `verify_*`, `deps_command_<name>`,
  `spec_migration`, `require_health`/`auto_health`, `health_threshold_*`).
- `platform.jimfile-cli` — blueprint-slot resolution, `now` timestamps,
  `valid-relpath`/`valid-id`, glob discovery.
- `platform.testlib` — the group's five test files run under the shared
  framework.
- `issue.emitter` + `issue.candidate-batch-contract` — violations,
  misalignments, and health findings are offered as tracked issues through
  `new.sh`/`index.sh` per the § 7a contract.
- `sdlc.personas` — skill frontmatter binds `agent: architect` (blueprint,
  partition) and `agent: reviewer` (verify); a prose/frontmatter channel, not
  a code composition.

- `skills/blueprint/` — `SKILL.md` (generate, update, project tier, reconcile,
  retire, migrate arms), `assets/{blueprint,map}-template.md`, and references:

  gate-presentation, present-tense, provenance, migrate-arms.

  (a literal-path territory entry at the repo root).
