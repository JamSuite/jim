## Description

## Description

`/jim:blueprint` runs a present-tense scan and a provenance scan before every
write, with a dedicated reference for each:

- `skills/blueprint/references/present-tense.md`
- `skills/blueprint/references/provenance.md`
- invoked at `skills/blueprint/SKILL.md:157-163`, on both the generate and the
  targeted-update paths, itemizing each rewrite in the summary.

`/jim:arch` has neither. `skills/arch/SKILL.md` contains no present-tense or
provenance step, and the skill has no `references/` directory at all.

The result is visible in the artifact. `ARCHITECTURE.md` currently carries **136**
`spec NNN` / `issue/NNN`-style provenance citations — "spec 035 adds a third…",
"issue/011 added the `place.sh` placement primitive", plus component descriptions
that read as a changelog of which spec added which verb.

Both files describe current state and are regenerated by their own skill. One is
held to a rule the other is not, and no reader is told why.

## Why it matters beyond tidiness

A spec-id citation rots when the thing it names moves — which is exactly what the
`rename` and `split` verbs do to spec ids. The blueprint surface's provenance
rule exists for that reason, and the same reason applies unchanged here. It is
also the rule this project applies to its own script comments (`CLAUDE.md`:
comments state current behavior, not provenance).

Separately, `tests/docsurfaces.sh` exempts `ARCHITECTURE.md` from its retirement
corpus on the grounds it is regenerated rather than hand-edited. That premise is
itself worth checking — at least one commit hand-edited it substantially rather
than regenerating.

## Action

Decide whether the present-tense and provenance rules are blueprint-specific or
doc-surface-general. If general — which the argument above suggests — give
`/jim:arch` the same two scans, pointing at the blueprint surface's references
rather than restating them, and let the next regeneration normalize the 136 sites
rather than doing it by hand.

If the answer is that `ARCHITECTURE.md` deliberately keeps a historical voice,
say so in the skill, so the asymmetry reads as a decision rather than an
oversight.
