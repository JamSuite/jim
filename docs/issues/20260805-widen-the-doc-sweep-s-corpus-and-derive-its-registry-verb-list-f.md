## Description

`tests/docsurfaces.sh`, added this build as the durable half of the doc-drift
work, has a corpus hole and a derivation hole.

**Corpus.** `doc_corpus` (`:50-58`) visits 50 files and omits 23 hand-authored
surfaces — every `agents/*.md` body and every `skills/*/assets/*.md` template:

```
printf 'Run the vacated-max verb to reset the ceiling.\n' >> agents/coder.md
printf 'Use `jimledger.sh mv-spec` to move it.\n'        >> skills/plan/assets/plan-template.md
bash tests/docsurfaces.sh retired   -> PASS

printf 'See [the step](#no-such-heading-anywhere).\n'    >> agents/reviewer.md
bash tests/docsurfaces.sh anchors   -> PASS
```

The same symbols in `skills/file/SKILL.md` fail correctly, so the sweeps are live
— just aimed too narrowly. Five omitted files invoke the very scripts whose verbs
get retired (`agents/reviewer.md`, `agents/judge.md`, `agents/gatherer.md`,
`skills/review/assets/review-template.md`, `skills/blueprint/assets/map-template.md`).
The file's header justifies excluding `ARCHITECTURE.md` and `docs/{notes,issues,specs}`
and gives no reason for `agents/` or `assets/`. Its sibling in the same suite,
`tests/fanoutdisclosure.sh:46-49`, already defines a corpus that includes both.

The fail-closed guard conceals the gap: `assert_eq "the doc corpus enumerated
(>= 10, got $n)"` sees n=50 and reports health.

**Derivation.** The registry-verb check hard-codes `verbs=('sweep' 'catch-up'
'lift')` at `:123`, while its adjacent ledger-verb check derives the list from
jimledger's dispatch table at `:61-64`. Adding a fourth registry verb passes;
adding a fourth ledger verb fails with `got [audit-trail]`. The comment at
`:115-117` asserts the property the hard-coded half does not have: "A fourth verb,
or a fourth surface, has to be added everywhere or fail here."

**Vacuity.** The retirement half currently guards a corpus none of its four
retired symbols has ever occupied — every live occurrence sits in a file the
corpus deliberately excludes. It has real value against future reintroduction and
zero coverage of where they live now. And the one file exempted for being
"regenerated by `/jim:arch` rather than hand-edited" is the file this build
hand-edited, and where the surviving stale site lives.

## Proposed action

Widen `doc_corpus` to `agents/*.md` and `skills/*/assets/*.md`, matching
`fanoutdisclosure.sh`'s corpus, and add a per-root enumeration assertion so
dropping a root fails rather than being absorbed by the floor.

Derive the registry verb list from `jimalloc.sh`'s dispatch table the way
`ledger_verbs()` already does.

Decide the `ARCHITECTURE.md` exclusion: either include it (its five legitimate
"retired in <spec>" markers can be exempted by that phrase) or drop the three
symbols that only live there and say so, since today the green is uninformative.
